## 2. Lucian UX/UI の採用・不採用

検索した: button / toggle / radio / segmented / input / select / progress / empty state / toast / badge / tabs / table。

- **不採用（全部）**。理由: 候補（001 Liquid glass button・013 Stretchy switch・015 Plan radio cards・039/048 tabs・070 Stacking toasts・083 Queue bar・092 Empty search）はどれも動きを見せる固定サイズのデモ部品。この画面に必要なのは 44px の押しやすさ・状態の言葉・既存の流れで、動きを足しても利用者の詰まりは減らない。015 はプランを「選んで確定」にすると今の「カードごとに確認して切り替え」の流れが変わる。070 は「最新1件だけ・成功は消えエラーは残す」（未決4）に対して重ねて並べる作りで方針が逆
- 採用したのは考え方だけ: 070 の「成功は自動で消え、エラーは残る」→ 運営のジョブ一覧の通知（`admin.js` の `notice`）

## 3. 画面別（前 → 後 → 理由）

各画面とも 検品4点（導線・コントラスト・ボタンの言葉・らしさ）と状態（0件・完了後・エラー・停止中）を見て、優先して直す所を最大3つ選んだ。

### 共通（app.css）
1. 配色・文字・余白をトークン化 → 画面ごとにばらばらだった淡色（#EEF5FD／#E7F1FC／#F0F6FF）や #fff/#000 ベタをなくした
2. 共通部品: 選ぶ行 `.choice`・2択 `.seg`（丸印を文字に重ねず横に並べる）・スイッチ `.sw`・お知らせ面 `.notice`（情報／注意／無地）
3. 見出しとボタンの長い文言は語の切れ目で折り返す（`word-break:auto-phrase`）

### ログイン・Instagram 名・同意・退会後
- 同意: チェックが入っていない「同意してはじめる」に押せない理由がなかった → 「同意のチェックを入れると押せるようになります」→ 押せないボタンの理由が分かる（チェックで消える）
- Instagram 名: 「登録して次へ」→「登録して規約の確認へ進む」→ 押した先が分かる言葉。「あとで入れる」は補助ボタン（薄グレー）にして主と副を見分ける
- 退会後: 唯一の次の行動が副ボタン → 主ボタン
- ログイン: トークンのみ（補足 14px で読みやすく）。エラー表示（`?e=line`）も確認

### ホーム
1. **契約の状態（未決1）**: 残量カードの見出しの下に active「次の更新日 11月16日」・canceling「解約処理中（11月5日まで使えます）」（赤茶）。past_due は既存の停止表示のまま
2. **停止中の文言（未決2）**: 「新しい送信と書き出しはできません。完成したものは保存期限まで保存できます。」を停止表示に
3. 空状態「ここに並びます」だけ → 「上の『動画を送る』『写真を送る』から、最初の1本を送ってみてください」を添える（DESIGN の「最初の1本」）。停止中は送るボタンが無いので添えない
- ほか: 一覧の補足 13→14px・状態ラベルを角丸6pxの小さな札（押せるボタンと形で分ける）・320px で「あと10分0秒」が途中改行しない

### 送る（動画・写真）
- 動画/写真の切り替えが「塗りのボタン2つ」→ ライン型のタブ（選択中は青文字＋太線）→ 切り替えだと分かる
- 選ぶ枠の補足 13→14px・ホバーで淡い青。途中まで送った案内を共通のお知らせ面に
- 停止中（お試し終了）の写真タブは理由＋「プランを比較する」を確認

### 写真: 残す顔を選ぶ（pick・未決3）
1. **番号札の重なり**: 密集すると番号札（枠の左上の外側寄り・12px）同士と 44px 当たり判定の疑似要素が重なっていた（overlap 15件）→ 番号札は枠の **内側** 左上に 11px で、「枠に収まる・ほかの枠と 4px 以上離れる・見えている範囲にある」ときだけ出す。密集時は番号を省き **色＋太さ＋塗り**（残す＝緑3px＋塗り／モザイク＝オレンジ2px）で示す。拡大・スクロール・自信の低い枠の切り替えのたびに置き直す（判定・座標・送る値は同じ）
2. 小さい枠を 44px 四方で押せる仕組みを疑似要素 → 押した点の判定に置き換え（重なっていれば上＝小さい枠を優先＝今までと同じ順）。キーボードは各ボタンのまま。拡大中に見えない枠は描かない
3. 2択（ブロック粗め／すりガラス）の丸印を共通部品に
- 結果: 390/320 とも 初期・2つ選択後・拡大＋自信の低い枠表示 で overlap `[]`。実際に小さい枠（枠6）を中心タップで選べ、書き出し→できあがりまで通る

### 写真: できあがり
- 保存2つ・もう1枚送る・選び直すが同じ並び → 保存の2つ／「もう1枚送る・選び直す」を区切り線で分ける（中＜外）
- 消えた後は唯一の行動「もう1枚送る」を主ボタンに（空の保存まとまりの区切りも出さない）
- 320px で「ファイルに保存する（ダウンロード）」が「ド）」だけ改行していた → 語の切れ目で折り返す

### 動画: 処理中・場面から選ぶ・確認・できあがり
- 場面から選ぶ: pick と同じ当たり判定に。✓ 札は余裕のある枠だけ・選択は緑の太線＋塗りで示す。拡大表示（全面ダイアログ）の間は後ろの画面を描かない。#000/#111 → `--dark` 系
- 確認: 2択を共通部品に。空の列「ありません」だけ → 「…でタップすると、ここに移ります」と次の操作を添える。320px で切り抜きの札（モザイク／秒）が1文字ずつ折れていた → 札ごとに折り返さない
- 処理中: 「閉じても大丈夫です」をお知らせ面に・目安の数値を途中改行しない。失敗・削除済みの表示も確認
- できあがり: 写真と同じまとまり分け。選び直しの書き出し失敗の知らせを保存ボタンの上へ

### プラン比較
1. 「受付は準備中」「解約処理中のため変えられません」がページの一番下 → プラン一覧の前（押せない理由をボタンより先に）
2. 「月\n1,980円」「＋500円/月」が途中で折れていた → 金額と単位をひとまとまりに
3. いまのプランは枠 2px＋札、金額は等幅数字

### 設定・問題の報告・退会
- 設定: まとまりの間 16→24px・見出しを本文色に・項目名を補足色にして値と見分ける。ログアウトを補助ボタンに（退会は小さなリンクのまま）
- 問題の報告・退会: 選ぶ行・入力欄・注意書きをトークンに揃える（選んだ行は青枠＋淡い青＋太字）。未選択で送ったときのエラー位置（選択肢の上）も確認

### 法務（見出し・余白・読みやすさだけ。本文は変えていない）
- 条の見出しの上に区切り線と余白・行の高さ 1.75・今のページに青の下線
- 特商法の料金表: 月額の列を右揃え（比べる金額）・「500\n円」の改行をなくす

### 運営画面（1280/1024）
1. **ジョブ一覧の知らせ（未決4）**: 成功文とエラー文の2つの領域 → 通知領域1つに最新だけ。成功（緑の面）は 4 秒で消え、エラー（赤茶の面）は次の操作（もう一度処理する・削除・タブ切り替え）まで残る
2. 1024px で失敗理由の列が細く縦長・利用者名が2行 → 失敗理由は最小 200px・利用者名は折り返さない
3. ダッシュボードで一覧へ飛べるタイルと表示だけのタイルが同じ見た目 → 押せるタイルだけ「一覧を見る ›」とホバーの淡い青
- 利用者・利用者詳細・通報（開いた状態）・設定はトークン適用のみで overlap `[]`

## 5. 残っていること
- 動画の確認画面（vreview）は、ページ先頭のまま見ると、下に固定した「この内容で書き出す」バーの裏に切り抜きが来るため overlap-check が重なりとして数える（固定バーの上を内容がスクロールする作り）。最後までスクロールした状態では `[]`（最後の切り抜きがバーに隠れない）
- 合言葉モード（`index.html`）は AUTH_MODE=line の E2E では開けないため、トークンの反映を画面で見ていない
- Stripe 未設定の E2E のため、プラン比較の「このプランにする」が押せる状態・解約処理中の「変えられません」表示は画面で見ていない（配置の変更だけ）
- `/static` はキャッシュの指定がなく、ブラウザが古い app.css を使い続けることがあった（E2E で発生）。本番反映後に古い見た目が残る可能性がある
