# LINE 通知テンプレート（らくちんモザイク）

作成 2026-10-26。利用者に Messaging API の push で送る文面の一覧。文面の正本はコード（下表の「定義場所」）で、ここは見直し用の写し。文面を変えるときはコードを直し、この表も同じに更新する。

共通ルール
- 末尾に必ずアプリのリンクを付ける（#8 withdrawn を除く。`APP_BASE_URL` ＋ 画面パス ＋ `?openExternalBrowser=1`）。リンクはコード側が自動で付ける
- LINE 通知を OFF にしている人・退会済みの人には送らない。同じ内容はホームの一覧や設定画面にも出る
- 金額は「1,480円」のように3桁区切り、日付は「11月26日」のように月日だけ
- 解約・返金・自動退会など契約の条件は、設計書 2節「契約・解約・決済失敗の条件」と同じ言い回しにする

reply（Webhook 応答）
- 公式アカウントの Webhook（`POST /line/webhook`）に届いたイベントへ、reply（`replyToken`）で1回だけ返す。末尾に `APP_BASE_URL/?openExternalBrowser=1` を自動で付ける。定義場所は `app/services/notify.py` の REPLY_TEXT
- 友だち追加（follow）: 友だち追加ありがとうございます。アプリはこちらから使えます。
- メッセージ（text）: こちらから使えます。（会話はしない。スタンプ・画像などには返さない）
- ブロック（unfollow）は返信せず、その利用者の LINE 通知を OFF にする

送らないもの
- 下位プランへの変更・高画質オプション外し（次の更新日に適用・請求なし）。画面に「次回から ○○ に変わります」と出す
- 毎月の更新の請求。本番モードでは Stripe のレシートメールで代える（設計書「本番移行チェックリスト」）

Stripe からのメール（本番モードのみ・設定で有効化）
- 領収書: 契約時・差額請求時・毎月の更新時（Stripe ダッシュボード → 設定 → 顧客メール → 成功した支払いのレシート）
- 支払い失敗のリマインダー・カード期限切れのお知らせ（設定 → Billing → サブスクリプションとメール）
- 解約確認のメールは Stripe にはない。解約の記録は #7 の LINE と設定画面の「解約処理中」表示
