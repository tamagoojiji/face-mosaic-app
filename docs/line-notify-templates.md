# LINE 通知テンプレート（らくちんモザイク）

作成 2026-10-26。利用者に Messaging API の push で送る文面の一覧。文面の正本はコード（下表の「定義場所」）で、ここは見直し用の写し。文面を変えるときはコードを直し、この表も同じに更新する。

共通ルール
- 末尾に必ずアプリのリンクを付ける（`APP_BASE_URL` ＋ 画面パス ＋ `?openExternalBrowser=1`）。リンクはコード側が自動で付ける
- LINE 通知を OFF にしている人・退会済みの人には送らない。同じ内容はホームの一覧や設定画面にも出る
- 金額は「1,480円」のように3桁区切り、日付は「11月26日」のように月日だけ
- 解約・返金・自動退会など契約の条件は、設計書 2節「契約・解約・決済失敗の条件」と同じ言い回しにする

| # | 種別 | いつ | 文面（{ } は差し込み） | リンク先 | 定義場所 |
|---|---|---|---|---|---|
| 1 | ready | 動画の解析が終わり、顔を選べるようになった | 選択の準備ができました。残したい顔をタップしてください。 | /pick/{job} | `app/services/notify.py` message() |
| 2 | done | 書き出しが終わった | できました。{保存日数}日間はいつでも保存できます。 | /done/{job} | 同上 |
| 3 | idle | 選択・確認を1時間放置 | まだ選択が残っています。あと{残り時間}時間で動画を削除します。 | /pick または /review | 同上 |
| 4 | failed | 処理に失敗した | 処理できませんでした（{理由}）。消費した分数は戻しました。 | /home | 同上 |
| 5 | payment_failed | 月額の決済に失敗した（Stripe の invoice.payment_failed） | お支払いが確認できません。7日以内にカード情報を更新してください。 | /settings | 同上 |
| 6 | plan_changed | 上位プランへ変更・高画質オプション追加（即時請求あり） | プランを {プラン名} に変えました。今回の請求 {差額}円。次回から 月{月額}円です。 | /settings | `app/services/billing.py` change() |
| 7 | cancel_requested | 設定の「解約する」を押した | 解約を受け付けました。{更新日}までは、いまのプランのまま使えます。{更新日}に自動で退会となり、保存している動画・写真も消えます。返金はありません。取り消すときは、設定の「支払いを管理する」→「プランを更新」から。 | /settings | `app/services/billing.py` cancel_at_period_end() |

送らないもの
- 下位プランへの変更・高画質オプション外し（次の更新日に適用・請求なし）。画面に「次回から ○○ に変わります」と出す
- 更新日の自動退会（Stripe の subscription.deleted）。退会済みの人には送れないため、解約受付時（#7）に日付を伝えておく
- 毎月の更新の請求。本番モードでは Stripe のレシートメールで代える（設計書「本番移行チェックリスト」）

Stripe からのメール（本番モードのみ・設定で有効化）
- 領収書: 契約時・差額請求時・毎月の更新時（Stripe ダッシュボード → 設定 → 顧客メール → 成功した支払いのレシート）
- 支払い失敗のリマインダー・カード期限切れのお知らせ（設定 → Billing → サブスクリプションとメール）
- 解約確認のメールは Stripe にはない。解約の記録は #7 の LINE と設定画面の「解約処理中」表示
