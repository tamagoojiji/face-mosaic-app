1. はじめに・登録

パレードやショーの動画・写真に映った観客の顔を、自動でモザイクにするアプリです。残したい人（ダンサーなど）の顔だけをタップすると、ほかの顔がモザイクになります。

使えるもの

  • iPhone の Safari、Android の Chrome（インストールはいりません）
  • LINE のアカウント（ログインに使います）

LINE の中のブラウザでは大きな動画の送信が途切れやすいので、Safari か Chrome で開いてください。

登録の流れ

  1. 「LINEでログインする」→ LINE の画面で「許可する」
  2. 公式アカウントの友だち追加を聞かれたら追加すると、完成などのお知らせが LINE に届きます（追加しなくても使えます）
  3. Instagram のユーザー名を入れる（任意。「あとで」で飛ばせます）
  4. 利用規約とプライバシーポリシーを確認し、チェックを入れて「同意してはじめる」

2. ホームの見方

  • 動画を送る・写真を送る: ここから始めます
  • 今月の残り: 今月あと何分（何本）・何枚送れるか。お試し中は残りの日数、有料プランは次の更新日も出ます
  • 最近の動画と写真: 送ったものの一覧。「選択中」「完成」などの状態と、消えるまでの時間が出ます。タップで続きから開けます

3. 動画にモザイクをかける

動画は有料プラン（動画A・動画B）で送れます。リリース記念の期間中は、お試しでも1分までの動画を送れます。

① 送る

「動画を送る」→「動画を選ぶ」で1本選ぶと送信が始まります。1本1.5GBまで、長さの上限はプランで決まります（動画Aは1分、動画Bは3分まで）。送信中は画面を開いたままにしてください。途中で切れても、同じ動画を選び直すと続きから送れます。

② 顔を探すのを待つ

届いた動画から顔を探します。順番待ちがあると、前に何件あるかと目安の時間が出ます。この間は画面を閉じても大丈夫です。終わると LINE でお知らせします。

③ 残したい人の顔を選ぶ

場面ごとの写真に、見つけた顔の枠が出ます。モザイクをかけたくない人の枠をタップすると緑になります。観客の顔は何もしなくてもモザイクになります。左右にスクロールすると別の場面、「拡大する」で大きく見られます。

④ 確認する

「モザイクをかける予定」「かけない予定」の2つの列を見比べます。違うものは顔をタップすると反対の列に移ります。モザイクの種類（ブロック粗め／すりガラス）もここで選びます。すりガラスは書き出しに少し長く時間がかかります。

⑤ 書き出して保存する

「この内容で書き出す」を押すと書き出しが始まります。閉じて待てます。できたら再生して確かめ、「動画に保存する」を押してください。

処理にかかる時間の目安

4K・60fps で撮った動画での実測です。4K・30fps や 1080p で撮った動画はこれより短くなります。

動画の長さ顔を選べるまで書き出し
1080p		書き出し
元の画質
30秒約3分約1分約7分
1分約5分約1分約15分

  • 混み合っているとき（ほかの方の動画が先に並んでいるとき）は、順番待ちの分だけ長くなります。前に何件あるかと目安の時間は画面に出ます。
  • この時間は今後のアップデートで短くなる可能性があります（数値は 2026年10月の実測です）。
  • 待っている間は画面を閉じても大丈夫です。終わると LINE でお知らせします。
  • 元の画質（4K など）での書き出しは高画質オプションの方だけです。確認画面で 1080p と選べます。

4. 写真にモザイクをかける

  1. ホームの「写真を送る」→ 写真を1枚選ぶ
  2. 数秒で顔に枠が出ます。残したい人の枠をタップ（緑になります。オレンジの枠はモザイクがかかります）
  3. 小さい顔が見つからないときは「自信の低い枠も表示」をオンにすると、候補が増えます
  4. モザイクの種類を選んで「この内容で書き出す」
  5. 「写真に保存する」（または「ファイルに保存する」）

5. 顔を選ぶコツ

  • 同じ人は場面が変わっても同じ人として扱います。1つの場面でタップすれば、ほかの場面でも残ります
  • ダンサーと同じ衣装の人が近くにいると、まとめて残ることがあります。確認画面の「かけない予定」に観客が混じっていたら、タップしてモザイク側へ移してください
  • 横顔・帽子・逆光の顔は見つけにくいことがあります。自動で見つけられない顔もあるので、投稿する前に完成品を必ず自分の目で確かめてください。
  • 選ばずに進むと、見つけた顔すべてにモザイクがかかります

6. 保存と保存期限

もの消えるまで
元の動画・写真と、顔を探した結果完成から24時間（その間は選び直せます）
完成した動画・写真30日（ホームの一覧から何度でも保存し直せます）
顔を選ぶ・確認の画面のまま1時間で LINE にお知らせ、3時間で元の動画ごと削除
送信の途中で止めたもの24時間

消えたあとは戻せません。必要なものは早めにスマホに保存してください。

7. お試しとプラン

お試し（無料）

登録から7日間、写真を5枚まで送れます（動画はなし）。リリース記念の期間中は、写真10枚と1分までの動画3本に増えます。8日目からは、プランを選ぶまで新しい送信と書き出しはできません（完成したものは保存期限まで保存できます）。お試しは LINE アカウントごとに1回だけです。

月額プラン

プラン通常価格記念価格動画（1か月）1本の長さ写真（1か月）
画像のみ1,000円500円なし−100枚
動画A1,480円980円10分1分100枚
動画B1,980円1,480円90分3分無制限
高画質オプション＋500円＋500円動画A・Bに付けられます

リリース記念価格は、運営が告知する期限までのお申し込みに適用し、契約を続けている間は記念価格のままです。期限のあとのお申し込み（解約・退会のあとの再契約を含みます）は通常価格です。

ふだんの書き出しは 1080p・30fps です。高画質オプションを付けると、元の解像度と fps（4K・60fps など）のまま書き出します（HDR の動画は通常の色に変換します）。スマホで見るだけなら差はほとんど分かりません。

申し込み

ホームの「プランを比較する」→ プランを選ぶ → カード情報を入れて支払うと、すぐ使えるようになります。お支払いはクレジットカード（Stripe）です。カード番号はこのアプリには保存されません。

8. プランの変更と高画質

  • 上のプランへ・高画質オプションを付ける: すぐに切り替わります。残りの日数分の差額を、登録しているカードにその場で請求します。押す前に請求額が表示されます
  • 下のプランへ・高画質オプションを外す: 次の更新日から変わります（請求はありません）。それまでは今のプランのまま使えます

元の画質での書き出しは 1080p の約 10〜15 倍の時間がかかります（1分の動画で約15分）。確認画面で毎回 1080p と選べます。

契約は1か月ごとで、契約した日と同じ日に毎月自動で更新されます。返金はありません（日割りもありません）。

9. 解約・取り消し・退会

解約（期間の終わりまで使う）

設定の「解約する」を押します。解約しても次の更新日まではそのまま使えます。更新日になると自動で退会となり、保存している動画・写真も消えます。返金はありません。解約したあと、無料のお試しには戻れません。

解約の取り消し

更新日までなら、設定の「解約を取り消す」で元に戻せます。これまでどおり更新されます。

退会（すぐにやめる）

設定のいちばん下の「退会する」→ 理由を選ぶ → 退会。すぐに退会となり、有料プランの残り期間も終わります（返金はありません）。動画・写真・Instagram のユーザー名はその場で消えます。

10. お支払いがうまくいかないとき

カードの期限切れなどで月額のお支払いができなかったときは、LINE でお知らせします。その間は新しい送信と書き出しが止まります（完成したものは保存できます）。設定の「支払いを管理する」からカード情報を更新すると、元どおり使えます。7日たってもお支払いが確認できないときは、次の更新日に自動で退会となります。

11. LINE のお知らせ

公式アカウントを友だち追加していると、次のときに LINE でお知らせが届きます。

  • 顔を選べるようになったとき・完成したとき・処理できなかったとき
  • 選ぶ途中のまま1時間たったとき（あと2時間で削除）
  • 登録・申し込み・プランの変更・解約・解約の取り消し・退会・お支払いの失敗

友だちになっていないとホームに「完成の通知を LINE で受け取る」が出ます。「公式アカウントを追加する」から追加（ブロック中なら解除）してください。お知らせは設定でオフにもできます。届かなくても、同じ内容はホームの一覧に出ます。

12. 設定でできること

  • プランと契約の状態の確認、プランを比較する
  • Instagram のユーザー名の登録・変更（任意）
  • LINE のお知らせのオン・オフ
  • 支払いを管理する（カードの変更・請求の履歴）、解約する・解約を取り消す
  • 問題を報告する、使い方の説明書、ログアウト、退会する

13. 問題を報告する

うまくいかなかったときは、設定の「問題を報告する」から運営に知らせてください。

  1. うまくいかなかったところに近いものを1つ選ぶ（送る・顔を選ぶ・仕上がり・保存と通知・ログインと契約・その他）
  2. 内容を書く（任意。「その他」を選んだときだけ必要です）
  3. 対象の動画・写真を選ぶ（任意）
  4. スクリーンショットを付ける（任意・3枚まで・1枚10MBまで）
  5. 「運営に報告を送る」

14. よくある質問

動画や写真は誰かに見られますか？
顔の検出はこのアプリのサーバーの中だけで行い、外部の AI サービスには送りません。元の動画・写真は完成から24時間で消えます。
縦の動画は縦のまま仕上がりますか？
はい。撮ったときの向きのまま書き出します。
音は残りますか？
残ります。モザイクをかけるのは映像だけです。
送信が途中で止まりました。
Wi-Fi の良い場所で、同じ動画をもう一度選ぶと続きから送れます。LINE の中のブラウザではなく Safari か Chrome で開いてください。
今月の分を使い切りました。
翌月の1日に戻ります。すぐに使いたいときは上のプランに変更できます（差額をその場で請求します）。
処理できなかったときの分数はどうなりますか？
処理できなかった動画の分数は今月の残りに戻します。
時間がかかりすぎていませんか？
3分の動画なら、顔を選べるまで約14分、1080p の書き出しに約3分が目安です（4K・60fps で撮ったとき）。元の画質での書き出しは1分の動画で約15分かかります。急ぐときは 1080p を選んでください。目安より大きく遅いときは、ほかの方の動画が先に並んでいます。順番は画面に出ます。
ログアウトするには？
設定の「ログアウト」。次に開くときは LINE で入り直します。
問い合わせ先は？
アプリ内の「問題を報告する」か、contact@tetraris.com へ。
