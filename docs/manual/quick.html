らくらくモザイク（アプリ内の表示は「顔モザイク」）

かんたん使い方 ― 1本仕上げるまで

送って、タップして、投稿へ。はじめての方が動画を1本仕上げるまでの流れです。全部の機能はくわしい説明書にあります。

はじめる前に
  • iPhone の Safari か、Android の Chrome で開きます（LINE の中のブラウザでは大きな動画の送信が切れやすいため）
  • LINE のアカウントが必要です
  • 無料のお試し（登録から7日間）で送れるのは写真5枚までです。動画は有料プラン（動画A・動画B）で送れます。写真の流れも下とほぼ同じです

  1. 1LINE でログインする

    「LINEでログインする」を押します。LINE の画面で、このアプリに名前などを伝えてよいかを聞かれるので「許可する」を押してください。

  2. 2規約を確認して同意する

    Instagram のユーザー名を聞かれます（入れなくても使えます）。次に約束ごとを読み、チェックを入れて「同意してはじめる」。

  3. 3ホームで「動画を送る」

    ホームには、今月あと何本・何枚送れるかと、お試しの残り日数が出ます。

  4. 4動画を1本選ぶ

    「動画を選ぶ」を押して1本選ぶと、すぐに送信が始まります。

    1本1GBまで。長さの上限はプランで決まります（動画Aは1分まで）。

  5. 5顔を探し終わるのを待つ

    届いた動画から顔を探します（数分。画面に目安が出ます）。閉じても大丈夫です。終わると LINE でお知らせします。

  6. 6残したい人の顔をタップ

    場面の写真で、モザイクをかけたくない人（ダンサーなど）の顔の枠をタップします。緑になれば選べています。観客の顔は何もしなくてもモザイクになります。

    左右にスクロールすると別の場面が出ます。「拡大する」で大きく見られます。

  7. 7確認して書き出す

    「モザイクをかける予定」「かけない予定」の2つの列を見比べます。違っていたら顔をタップすると、もう一方の列に移ります。よければ「この内容で書き出す」。

  8. 8できあがったら保存する

    再生して確かめ、「動画に保存する」を押します。完成した動画は30日間、ホームの一覧からいつでも保存し直せます。

    書き出しも閉じて待てます。できると LINE でお知らせします。

覚えておくこと

  • 元の動画は24時間で消えます。選び直しはそれまでにしてください
  • 完成した動画・写真は30日で消えます。必要なものは早めに保存してください
  • 顔を選ぶ画面・確認の画面のまま3時間たつと、元の動画ごと消えます（1時間たつと LINE でお知らせします）
  • 顔の自動検出は、すべての顔を見つけられるとは限りません。投稿する前に、仕上がりを自分の目で確かめてください

写真のとき

ホームの「写真を送る」→ 写真を1枚選ぶ → 残したい顔の枠をタップ →「この内容で書き出す」→「写真に保存する」。その場で数秒〜十数秒で終わります。

こまったとき

設定の「問題を報告する」から運営に知らせられます。料金・解約・よくある質問はくわしい説明書へ。
