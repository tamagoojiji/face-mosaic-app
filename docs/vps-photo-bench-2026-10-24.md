- VPS: Contabo 4コア / 7.9GB / swap 4GB、36コンテナ同居（計測時の docker stats 合計 CPU 9.1%・メモリ 2.9GiB）
- 環境: 既存イメージ `mosaic-bench:latest`（python:3.11-slim + ffmpeg + opencv-python-headless 5.0.0 / numpy 2.4.6 / Pillow 13.0.0、1.18GB・中身312MB）を流用。新規 venv は作っていない（インストール時間 0）

- 実行: 1枚ごとに `docker run --rm ... nice -n 10 python3 bench_photo.py`。秒数はプロセス内計測、「起動込み」はホスト側の docker run 全体
- 画像: 19枚（詳細は末尾の注）。転送 46.4MB を scp で 85.4秒（約 0.57MB/s、自宅回線の上り）

## VPS 6（6コア12GB）での見立て
- 1枚の処理は12MPで1.7秒、24MPで最大4.7秒。リクエストごとに docker run すると +1.5秒かかるため、Web版はモデルを読み込んだまま常駐するプロセスで受けるのが前提
- メモリは12MPで1枚0.7GB、24MPで1.4GB。同時3〜4件（24MPが重なる最悪で約5.6GB）なら他コンテナ込みでも12GBに収まる。アップロード時に長辺4000px以下に縮めれば1件0.7GB以下に抑えられる
- CPUは1件で約2コアを使うので、6コアで快適に同時処理できるのは約3件。それを超える分はキューで待たせる設計にする
